> SSH 终端 + 报错即诊 + 自然语言生成命令 + 免 Agent 监控 + SFTP

- 🤖 **BYOK 直连 AI**：自带 Key，报错贴上去直接给出诊断与修复命令

- 🖥️ **跨平台**：macOS / Windows / Linux 全覆盖，基于 Tauri 2 + Rust，轻量不臃肿
- 📦 MIT 开源，欢迎 Star & 提 Issue
